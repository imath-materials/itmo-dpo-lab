Доставка учебного продукта

Один контент — несколько способов публикации

Публичный статический портал: на GitHub Pages для демонстрации руководству, в Moodle — отдельные ссылки или iframe при разрешённых настройках. Оценки и дедлайны остаются в LMS.

Способ A · безопасный и простой

Добавить в Moodle элемент «URL / Ссылка» на нужную страницу GitHub Pages. Содержимое обновляется на сервере, LMS хранит ссылку и своё задание.

Предпочтительно

Способ B · встроенная страница

Вставить iframe в HTML редактор Moodle, только если политика домена и настройки редактора допускают встраивание; иначе iframe может быть очищен или заблокирован.

Зависит от Moodle

Способ C · LMS как система учёта

В Moodle создать Assignment/Задание с собственными сроками, рубрикой и обратной связью. Стенды используются как учебное содержание, но не передают оценки автоматически.

Способ D · офлайн-раздатка

Распаковать ZIP и открыть index.html в браузере без сети. Формы/симуляторы работают локально; внешние ссылки на LLM требуют интернета.

Прямая интеграция в курс

Готовые страницы можно привязать к темам Moodle отдельно, не раскрывая весь демонстрационный портал.

Генератор кода встраивания

Замените адрес на свой, после публикации проверьте режим просмотра под ролью слушателя. Если встраивание не работает — используйте URL как отдельный ресурс.


Граница интеграции: клиентские чек-листы хранятся только в localStorage браузера; они не ставят оценку в Moodle. Не вводите реальные персональные данные в опубликованный стенд: GitHub Pages — публичный статический хостинг.
