Где встретятся термины

При наведении или чтении незнакомого слова можно перейти сюда из практикума. Примеры приведены на учебном процессе обработки обращений.

Workflow

Схема действий и связей, выполняемая в n8n.

Пример: В учебном процессе это получение заявки, её проверка и выбор маршрута.

Разобрать на примере →

Trigger / триггер

Узел или событие, с которого начинается выполнение.

Пример: Ручной запуск, отправка формы, расписание.

Разобрать на примере →

Node / узел

Один шаг обработки, проверки или передачи данных.

Пример: IF сравнивает поле, Data Table сохраняет запись.

Разобрать на примере →

Canvas / холст

Рабочая область редактора, где соединяются узлы.

Пример: На холсте видно путь от формы к результату.

Разобрать на примере →

Execution / выполнение

Один конкретный запуск workflow с входными и выходными данными.

Пример: Разбор двух запусков: корректного и ошибочного.

Разобрать на примере →

Item / элемент данных

Один обрабатываемый объект; в узлах часто представлен полем json.

Пример: Одна заявка со свойствами topic, priority и description.

Разобрать на примере →

JSON

Текстовый формат структурированных данных: ключи, значения, массивы и объекты.

Пример: {"topic":"Аудитория 101","priority":"Обычный"}.

Разобрать на примере →

Data mapping / сопоставление полей

Передача значения из одного узла в параметр следующего.

Пример: В таблицу записывается topic, полученный из формы.

Разобрать на примере →

Expression / выражение

Подстановка или вычисление значения на основе данных запуска.

Пример: {{ $json.topic }} берёт поле topic текущего item.

Разобрать на примере →

IF

Узел выбора ветки по проверяемому условию.

Пример: Если valid=true, заявка принята, иначе требуется уточнение.

Разобрать на примере →

Form Trigger

Триггер, который создаёт веб-форму и получает введённые данные.

Пример: Поля «Тема», «Описание», «Приоритет».

Разобрать на примере →

Test URL

Адрес формы для отладки в редакторе n8n.

Пример: Позволяет видеть входные значения во время теста.

Разобрать на примере →

Production URL

Адрес формы для опубликованного workflow.

Пример: Используется после проверки и публикации процесса.

Разобрать на примере →

Data Table

Встроенная таблица n8n для структурированных записей.

Пример: Учебный реестр обращений с полями и статусами.

Разобрать на примере →

Credential

Конфигурация доступа к внешнему сервису, которую хранит n8n.

Пример: SMTP и внешний API требуют соответствующих прав.

Разобрать на примере →

API

Согласованный интерфейс, через который программы обмениваются запросами и ответами.

Пример: Получить сведения из системы по HTTP.

Разобрать на примере →

HTTP Request

Узел отправки HTTP-запросов к внешней системе.

Пример: GET для чтения, POST для отправки данных.

Разобрать на примере →

OAuth / токен доступа

Механизм, позволяющий подтвердить право запроса с ограниченным сроком действия.

Пример: GigaChat API использует авторизацию и временный токен.

Разобрать на примере →

SMTP

Протокол отправки почтовых сообщений.

Пример: Уведомление ответственному после проверки заявки.

Разобрать на примере →

Webhook

HTTP-адрес, который принимает внешнее событие.

Пример: Система сообщает n8n о новой записи.

Разобрать на примере →

Retry / повтор

Повторная попытка выполнения действия после сбоя.

Пример: Имеет смысл при временной недоступности API, но может создать дубли.

Разобрать на примере →

Идемпотентность

Повтор одного действия не должен создавать лишние результаты.

Пример: Повторная отправка формы не должна создавать две одинаковые заявки.

Разобрать на примере →

LLM / языковая модель

Модель обработки естественного языка; может ошибаться и создавать несуществующие данные.

Пример: Определить предварительную категорию свободного обращения.

Разобрать на примере →

Человек в контуре

Этап, на котором сотрудник проверяет и подтверждает значимое решение.

Пример: Сотрудник утверждает приоритет или отправку письма.
