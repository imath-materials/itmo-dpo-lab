Хорошая автоматизация не обязана быть большой. Она должна запускаться, обрабатывать входные данные, выдавать полезный результат и не разрушаться при первой неожиданности.

Критерии проекта

Ниже — учебная рубрика для самопроверки. Официальные правила зачёта, вес критериев и формат защиты определяет преподаватель курса.

Задача и границыКому и зачем нужен результат«Автоматизировали всё» без предмета
Работающий запускТриггер и входные данныеНет воспроизводимого запуска
Логика обработкиУсловия, выражения и преобразованияУзлы не связаны с задачей

ТестыОбычный и проблемный случаиПоказ одного удачного запуска
БезопасностьДанные, права, человек в контуреСекреты в JSON, автоматическое решение без контроля

Что сдавать вместе с проектом

  • Название задачи и схема из 3–8 ключевых шагов.
  • Экспорт JSON после удаления credentials и проверки содержимого полей.
  • Описание того, что нужно настроить после импорта (таблица, права, почта, API).
  • Два или более тестовых входа и зафиксированные результаты.
  • Короткое объяснение, что автоматически, а что проверяет человек.
Наличие рабочего JSON само по себе не доказывает качество: оцениваются запуск на подходящих данных и способность объяснить решение.

Диагностика типовых проблем

Form Trigger не запускает весь workflow

Для тестирования используйте Execute Workflow и Test URL. Execute Step в узле формы не обязательно запускает последующие узлы. Проверьте, не открыли ли Production URL без публикации workflow.

IF всегда отправляет данные в одну ветку

Посмотрите тип и фактическое значение поля во входе IF: строка «true» отличается от логического true. Проверьте пробелы, регистр и выбор оператора.

После импорта не работает Data Table

Экспорт не гарантирует существование таблицы и прав на неё в другом проекте. Создайте учебную таблицу и заново выберите её в узле. Не подставляйте чужой идентификатор.

HTTP Request возвращает 401 или 403

Проверьте, есть ли у учебной учётной записи права и корректная авторизация; не выкладывайте токены в чат или репозиторий. Ошибка авторизации не решается отключением проверки сертификатов.

Письмо не пришло

Проверьте исполнение Email Send, получателя и разрешённую отправку через SMTP. В резервном варианте покажите сформированный текст письма в выходе узла, без отправки.

Модель вернула не JSON

Обрабатывайте ответ как недостоверный: фиксируйте ошибку разбора, отправляйте на ручную проверку. Не подменяйте некорректные поля случайными значениями.
