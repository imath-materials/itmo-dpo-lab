Практическая инструкция по n8n Form Trigger и условным веткам. Учебная форма принимает вымышленные данные; workflow определяет, можно ли принять запись или надо вернуть её на уточнение.

Пояснения к практике

Форма запускает процесс; IF проверяет смысл входа; отдельный этап контролирует риск передачи сведений.

Последовательность действий

  1. Посмотрите поля формы

    Откройте «Форма заявки». Проверьте подписи: «Тема», «Описание», «Приоритет». Заголовки полей важны: следующая нода читает именно эти ключи.

  2. Откройте Test URL

    Для отладки используйте тестовую ссылку формы. В редакторе n8n запустите тестовое выполнение или откройте форму через кнопку теста, затем отправьте запись. Для опубликованного процесса существует отдельная Production URL: не путайте их.

  3. Отправьте корректную запись

    Тема: «Нужен переходник для аудитории 101»; описание: «Требуется проверить наличие HDMI-переходника до занятия». Приоритет: «Обычный». Найдите на выходе поля topic, description, priority, valid.

  4. Отправьте неполную запись

    Тема: «ПК»; описание: «Сломался». Запустите повторно через тестовую форму. Здесь valid должно быть false, а результат — «Вернуть на уточнение».

  5. Разберите логику

    Откройте узел «Проверка полей». Он убирает пробелы по краям, ограничивает длину строк и проверяет минимальную длину. Сравните исходные ключи с нормализованными.

  6. Измените правило, а не интерфейс

    Предложите ещё одну проверку: например, помечать заявки без даты занятия как требующие уточнения. Сначала сформулируйте правило на бумаге; изменение workflow — дополнительный уровень.

  7. Проверьте две ветки

    В Executions сравните один успешный и один проблемный запуск. Не ограничивайтесь сообщением формы «заявка получена»: оно не означает, что заявка действительно обработана.

Тест и публикация

Test URL используется для проверки в редакторе; Production URL — только после сохранения и публикации рабочего процесса. Во время обучения достаточно тестового маршрута.

Если тестовый URL не открывается, проверьте, что тестовое выполнение ожидает отправку формы. Если не видно входных данных, убедитесь, что открыли именно execution тестового запуска. Подробности — в словаре Test URL.
