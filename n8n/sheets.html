Где хранить результат?

В n8n можно хранить небольшой учебный реестр во встроенной Data Table, вести совместную таблицу во внешнем сервисе или выгружать файл. Самый простой способ не всегда лучший для реального подразделения.

ВариантКогда выбиратьВопрос безопасности
Data TableУчебная форма и небольшой внутренний реестрПрава проекта, видимость записей и срок хранения
Google SheetsСовместная таблица, готовая интеграция с n8nOAuth, региональный доступ, разрешённость передачи данных
Яндекс ТаблицыПривычная табличная работа и обработка текста с =ИИНе обещаем готовую эквивалентную интеграцию n8n; выбираем ручной импорт/экспорт либо согласованный API-маршрут
CSV/файлПереносимый результат и резервный вариантКто получает файл и где его хранит

Маршрут А. Google Sheets и n8n

У n8n есть штатный узел Google Sheets. Для соединения нужен настроенный способ авторизации; процесс получения OAuth-доступа может отличаться в self-hosted окружении.

  1. Создайте пустую учебную таблицу

    Добавьте заголовки request_id, category, status, created_at. Используйте только вымышленные данные.

  2. Проверьте подключение

    В учебном проекте n8n найдите Google Sheets node. Если credential недоступен, не создавайте приложение Google Cloud самостоятельно без указаний администратора.

  3. Добавьте Append Row

    Сопоставьте выходные поля обработанной заявки со столбцами таблицы. Сначала отправьте одну тестовую запись.

  4. Проверьте повторный запуск

    Две отправки одной заявки не должны создавать два независимых поручения без решения о дубликатах. Можно хранить request_id и проверять его перед записью.

Маршрут Б. Яндекс Таблицы

Для учебной работы используйте тот же файл и те же результаты, что и в Google Таблицах: скачайте XLSX с учебными обращениями. В Яндекс Диске поддерживается редактирование XLSX; CSV чаще открывается только для предпросмотра.

  1. Загрузите XLSX на Яндекс Диск

    Нажмите «Загрузить», выберите файл и откройте его двойным щелчком. На листе «Сводка» должны быть данные 12 / 7 / 7 / 6.

  2. Проверьте формулы и диаграмму

    Измените категорию одной учебной записи и сравните результат до и после изменения. При необходимости восстановите диаграмму.

  3. Верните данные в исходный вид

    Для последующей обработки через n8n выгрузите разрешённые тестовые данные. При этом контроль передачи файлов остаётся на человеке.

В чём различие с Google Sheets

В обоих редакторах слушатель получает одинаковый табличный результат. Но готовая интеграция n8n Google Sheets использует отдельный узел и авторизацию, а эквивалентной встроенной интеграции с Яндекс Таблицами здесь не предполагается. Не обещайте автоматическую синхронизацию без отдельного API-проекта.
