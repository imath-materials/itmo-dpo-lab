# Цифровые практики · ДПО ИТМО

Учебный сайт для двух самостоятельных программ:

- **Инструментальные возможности ИИ** — рабочие задачи, текстовые модели, визуальные материалы, данные, проект.
- **Автоматизация в n8n** — выбор процесса, данные и ветвления, ошибки, интеграции, онлайн-практика, проекты.

## Технология

Статический HTML + CSS + JavaScript. Без внешнего CDN, npm, сборки и сторонних библиотек. Сайт можно публиковать на GitHub Pages или выдавать отдельные страницы через Moodle (ресурс URL). Код не отправляет пользовательские данные на сервер. Карточки проектов выгружаются локально в Markdown.

## Как открыть

Откройте `index.html` в браузере. Все страницы, файлы и стили используют относительные пути и работают также в подпапке GitHub Pages. Ссылка для Pages этого репозитория: `https://imath-materials.github.io/itmo-dpo-lab/`.

## Состав

`ai/` — программа и четыре практикума с картой итогового проекта.

`n8n/` — учебные материалы, онлайн-практика, проектный интенсив, критерии.

`downloads/ai/` — синтетические данные и текстовые материалы.

`downloads/n8n/` — учебные workflow без credentials, требуют проверки импорта на целевой версии n8n.

`assets/` — оформление, доступность, копирование примеров и скачивание карточек.

## Обновление действующего репозитория

Не создавайте репозиторий заново. Распакуйте новый релиз в отдельную папку и выполните `scripts/install.ps1` (см. инструкцию в ответе), либо вручную синхронизируйте рабочее дерево и отправьте изменения через Git.

## Безопасность и ограничения

- В репозитории только синтетические учебные данные; не добавляйте реальные обращения, персональные данные, API-токены или рабочие credentials.
- Существующие учебно-демонстрационные n8n-экспорты со служебными параметрами не публикуются.
- JSON в папке `downloads/n8n` — учебные шаблоны, подготовленные по структуре подтверждённых экспортов, но не проверенные на рабочей инсталляции. Проверяйте импорт, поля форм и обе ветки перед выдачей группе.
- Точное расписание и официальные правила аттестации определяются организаторами в LMS.
- Указания по работе с GigaChat/Алисой предполагают учебные сведения и актуальный доступ конкретного пользователя.

## Методическая основа

Портал подготовлен на основе исходного документа «Ожидаемый результат ДПО», описаний двух программ и учебного архива `AI_Instruments`. Материалы бакалавриата адаптированы для сотрудников, а не объявлены программой ДПО. Описания n8n соответствуют учебным узлам и общеизвестным принципам автоматизации; за обновлениями следите в `https://docs.n8n.io`.
