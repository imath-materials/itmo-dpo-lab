# Два ДПО ИТМО · учебный портфель

**Редакция 07.11.2026 · Игорь Смирнов / Максим Санников**

Самодостаточный учебный сайт на HTML, CSS и JavaScript: четыре практикума первого ДПО, самостоятельный маршрут и симулятор n8n, методика интенсива, материалы для Moodle и полноэкранный режим показа руководству. Данные синтетические. Внешние библиотеки, CDN, ключи и backend для сайта не требуются.

> Внимание: тренажёры выполняются в браузере. Это не скрытые вызовы GigaChat или настоящей инсталляции n8n. Реальные интеграции и импорт учебного JSON требуют отдельной проверки.

## Быстрый запуск на Windows / PowerShell

1. Распакуйте архив. Убедитесь, что `index.html` лежит в корне распакованной папки.
2. В PowerShell перейдите в эту папку и выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\preview.ps1
```

Если Python не установлен, скрипт откроет `index.html` локально. Для живого показа лучше использовать локальный HTTP-сервер.

## Создать репозиторий в своём GitHub и опубликовать сайт

Нужны **Git** и **GitHub CLI**. В Windows PowerShell можно установить их через `winget`:

```powershell
winget install --id Git.Git -e
winget install --id GitHub.cli -e
```

После установки откройте **новое** окно PowerShell. Авторизуйтесь в своём аккаунте:

```powershell
gh auth login
gh auth setup-git
gh auth status
```

Установите имя и email для Git, если ещё не сделали этого:

```powershell
git config --global user.name "ВАШЕ ИМЯ"
git config --global user.email "ВАШ_EMAIL"
```

Из корня распакованного комплекта запустите:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\publish.ps1 -RepoName 'itmo-dpo-lab'
```

Скрипт запросит **YES**, чтобы подтвердить именно **публичную** публикацию. После этого создаст Git-репозиторий, отправит файлы в `main`, попробует включить GitHub Pages и покажет ссылки:

- `https://ВАШ_НИК.github.io/itmo-dpo-lab/`
- `https://ВАШ_НИК.github.io/itmo-dpo-lab/present.html`

Если автоматическое включение Pages не сработает: **GitHub → Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**. Репозиторий не должен содержать исходные закрытые экспорты или реальные данные сотрудников.

## Обновить сайт позже

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\update.ps1 -Message 'Обновлены практикумы'
```

## Где что лежит

| Путь | Содержание |

| `index.html` | Главная; доступ к двум ДПО |

| `sources/PROVENANCE.md` | Различение источников и собственных предложений |

## Реальная готовность и границы

- **Первое ДПО.** Готовы локальные упражнения, подсказки, демонстрационные данные и тесты. Для выдачи за настоящие результаты внешних моделей необходимы контрольные прогоны в GigaChat/Алисе AI и генераторе изображений. Визуальная серия в портале — процедурный SVG-макет, **не генерация нейросети**.
- **Второе ДПО.** Готовы методический маршрут, симулятор и учебный JSON без credentials. Импорт и выполнение этого JSON на сервере ещё **не подтверждены**. Два сложных исходных workflow находятся только в исходном архиве команды, **не в публичной сборке**.
- **Moodle.** Предпочтительно добавлять отдельные страницы как ресурсы URL. Встраивание iframe зависит от настроек LMS. Локальные чек-листы браузера не отправляют оценки в Moodle.
- **GitHub Pages.** Сайт публичен, даже если вы попросите поисковики не индексировать его. Не помещайте туда переписки, пароли, ключи, личные данные и конфиденциальные материалы. `robots.txt` не создаёт ограничений доступа.

Открытые организационные вопросы (дедлайны, пересечения расписаний, число ДЗ и права участников) — в `leadership/index.html`. Эти вопросы не считаются согласованными решениями.
