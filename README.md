# Цифровые практики — ДПО ИТМО

Учебные материалы двух самостоятельных программ: **«Инструментальные возможности ИИ»** и **«Автоматизация в n8n»**.

Сайт состоит из обычных HTML, CSS и JavaScript. Для чтения, копирования учебных запросов, тестов и заполнения рабочих карточек не нужен серверный API. Работа с моделями и n8n выполняется в реальных внешних интерфейсах, ссылки на которые находятся рядом с практиками.

## Что внутри
- `ai/` — практики и справочник по выбору сервисов (GigaChat, Алиса, Qwen, DeepSeek; Яндекс Таблицы, Google Sheets).
- `n8n/` — самостоятельная подготовка, подробные инструкции, онлайн-практика, темы про безопасную обработку данных, табличные интеграции и агентные системы, проектная работа.
- `downloads/` — только синтетические данные и учебные JSON без credentials.
- `assets/` — оформление, копирование запросов, авторасширение текстовых полей, локальный экспорт карточек и проверочные вопросы.

## Ограничения
- Скринкасты отмечены как планируемые. Записанных видео в этом релизе нет.
- JSON прошли структурную проверку и тесты отдельных Code-узлов, но требуют импорта и тестового запуска в целевой инсталляции n8n.
- `04_privacy_gate.json` — **учебный пример ограниченного фильтра**, не является полноценным обезличиванием и не подтверждает соблюдение требований законодательства.
- Доступность внешних сервисов, личных аккаунтов и тарифов зависит от среды и даты проверки.

## Moodle
Прямые ссылки на конкретные страницы можно добавить в Moodle как ресурс «URL» или внешнюю страницу. Доступы, оценки, сдача заданий и публикация видео остаются в закрытой LMS.

Не помещайте API-ключи, внутренние конфигурации, исходные реальные workflow или персональные данные в публичный репозиторий.
